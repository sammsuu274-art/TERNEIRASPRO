💡 DICAS IMPORTANTES
================================================================================

1. Leia tudo uma vez antes de executar
2. Use o script de automação (deploy_pythonanywhere.sh)
3. Faça backup antes de qualquer mudança
4. Documente suas alterações
5. Teste em ambiente local antes de produção
6. Mantenha .env seguro (nunca fazer commit)
7. Fazer backup local do db.sqlite3 frequentemente
8. Verificar logs se algo der errado
9. Seguir exatamente os passos (não pular)
10. Se não funcionar, procurar em DEPLOY_TROUBLESHOOTING.md

🔐 SEGURANÇA
================================================================================

⚠️  ANTES DE COLOCAR ONLINE:

□ Gerar nova SECRET_KEY (não usar a do desenvolvimento)
□ DEBUG = False (NUNCA True em produção)
□ ALLOWED_HOSTS preenchido com seu domínio correto
□ Trocar senha do admin (não deixar admin/admin123)
□ Arquivo .env não fazer commit
□ HTTPS verificado (PythonAnywhere fornece automaticamente)

================================================================================
📋 CHECKLIST PRÉ-DEPLOYMENT
================================================================================

Preparação:
  □ Conta PythonAnywhere criada
  □ Email verificado
  □ Projeto copiado para ~/TerneirasPro
  □ requirements.txt atualizado
  □ .env preenchido com valores corretos

Durante deployment:
  □ Venv criado em ~/venv
  □ Dependências instaladas (pip check OK)
  □ Migrations aplicadas
  □ Estáticos coletados em ~/TerneirasPro/staticfiles
  □ WSGI configurado em /var/www/seu_username_pythonanywhere_com_wsgi.py
  □ Static files mapeados em Web → Static files
  □ Reload feito

Pós-deployment:
  □ Sistema acessível em https://seu-username.pythonanywhere.com
  □ Tela de login funciona
  □ Login com admin / admin123
  □ Dashboard carrega
  □ Teste criar novo registro
  □ Dados aparecem no banco
  □ Logout funciona
  □ Backup feito
